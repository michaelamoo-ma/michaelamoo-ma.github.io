## Publish with GitHub Pages
1. Create or open the repository for your portfolio.
2. Upload **all files and folders in this ZIP** (especially `index.html` and `assets/`) to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose your main branch and the `/ (root)` folder, then save.
6. Open the GitHub Pages URL shown by GitHub.

Keep the `assets` folder in the same directory as `index.html` or images and certificate links will not load.
